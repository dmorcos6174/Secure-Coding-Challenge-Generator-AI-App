# Secure-Coding-Challenge-Generator-AI-App

Secure AI-Powered Challenge Application
This is a full-stack web application that leverages AI to generate unique challenges for users. The project features a secure, modern backend built with FastAPI and a dynamic, responsive frontend powered by React.

The core of the application is an AI-driven challenge generator that creates multiple-choice questions, offering an interactive and engaging experience for users. User authentication is handled securely via Clerk, ensuring that user data and session history are protected.

Key Features:

AI Challenge Generation: Utilizes a Python-based AI service to create dynamic multiple-choice questions on the fly.
Secure User Authentication: Implemented end-to-end user management and authentication with Clerk, including sign-up, sign-in, and protected routes.
Full-Stack Architecture: A clear separation of concerns with a RESTful API connecting the React frontend to the FastAPI backend.
Challenge History: Allows users to view their past activities and track their progress (if applicable).
Asynchronous Backend: Built with FastAPI for high performance and scalability.

Technology Stack:

Backend: Python, FastAPI
Frontend: JavaScript, React, Vite
Authentication: Clerk
Database: SQLModel/SQLAlchemy (or specify your DB)
